# Stay Capable After 55

Curated collection for CMPA 4301 Project 01.

**Topic:** Strength and conditioning for athletes who remain active after 55.

## How this repo is set up

| Piece | Role |
|-------|------|
| `content/` | Obsidian vault + published site source |
| `content/index.md` | Landing page for the published curation |
| Category folders A–E | Organization shelves |

## Edit in Obsidian

1. Obsidian → **Open folder as vault**
2. Select this folder’s `content/` directory (not the course repo root)
3. Edit Markdown notes as usual

## Publish on GitHub Pages

1. Create a GitHub repo and set this folder as the git root (already initialized locally)
2. Push to GitHub
3. Enable Pages (or a Quartz/static pipeline) with `content/` as the site content root so `content/index.md` becomes the public home

## Course note

Working bibliography, annotation bank, and checklists live in the parent course repo (`r-4301-online-management`). Published reader-facing text lives here under `content/`.
