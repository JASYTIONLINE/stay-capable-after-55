# C. Programming

This room answers **how to train**: how hard, how often, how much, how to keep power, and how to mix lifting with running, rucking, or martial arts. If you are coming back after time off, start in [[B-Returning-to-active-lifestyle/index|Returning to an active lifestyle]] first — earn the right to program hard. Use [[A-Evidence-filter/index|Evidence filter]] tools to judge new programs you find; come here for dose, standards, and concurrent-training evidence that fits people who still train after midlife.
